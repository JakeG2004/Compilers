## What is a compiler?
* Software which translates code from language 1 to language 2
    * eg C- (imaginary and made up) to C or C to ASM
* Front end and backend
    * Frontend translates user written code to middle ground understood language
    * backend translates middle language to target language
    * Can swap out front end and backend to achieve differente results (change frontend language, backend language, generate code report, etc...)
* Interpreters
    * Take code in frontend, then execute, one line at a time
